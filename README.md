# نظام تشغيل المقاولين — سقالة MVP (المرحلة 1)

تطبيق ويب حقيقي وقابل للتشغيل يُنفّذ **الأسابيع 1–3** من الخطة التنفيذية المتفق
عليها: مصادقة متعددة المستأجرين، إدارة مشاريع، تتبع الميزانية والمصروفات
(المخطَّط مقابل الفعلي)، وقائمة مهام لكل مشروع.

هذه ليست منصة إنتاجية جاهزة للإطلاق — إنها الأساس الذي تُبنى عليه الأسابيع
4–12 (عروض الأسعار، العقود، الفوترة، بوابة قبل/بعد) حسب خطة التنفيذ الكاملة.

## المكدس التقني

- **الخادم**: Node.js + Express + TypeScript، Drizzle ORM فوق PostgreSQL،
  مصادقة JWT، تحقق من المدخلات عبر Zod.
- **الواجهة**: React + Vite + TypeScript + Tailwind CSS، React Router،
  واجهة عربية RTL كاملة.
- **قاعدة البيانات**: PostgreSQL، نموذج بيانات متعدد المستأجرين (كل
  استعلام مُقيَّد بـ `company_id`).

## البنية

```
server/   Express API — مصادقة، مشاريع، ميزانية، مهام
client/   واجهة React (RTL)
```

## التشغيل محلياً

### 1) قاعدة البيانات

عبر Docker (موصى به):

```bash
docker compose up -d
```

أو عبر PostgreSQL مثبّت محلياً — أنشئ قاعدة بيانات فارغة وحدّث
`DATABASE_URL` في `.env` ليطابق بيانات الاتصال لديك.

### 2) متغيرات البيئة

```bash
cp .env.example server/.env
# ثم عدّل server/.env حسب الحاجة
```

### 3) التثبيت والتهيئة

```bash
npm install
npm run db:migrate --workspace server
npm run db:seed --workspace server   # بيانات تجريبية + مستخدم تجريبي
```

بيانات الدخول التجريبية بعد التهيئة:

- البريد الإلكتروني: `demo@contractor-os.test`
- كلمة المرور: `demo1234`

### 4) التشغيل

في نافذتي طرفية منفصلتين:

```bash
npm run dev:server   # http://localhost:4000
npm run dev:client   # http://localhost:5173
```

## نطاق هذه المرحلة (Phase 1 — Weeks 1–3)

- [x] مصادقة (تسجيل شركة جديدة + تسجيل دخول) بمعزل كامل بين المستأجرين
- [x] إدارة مشاريع (إنشاء، عرض، تعديل، حذف)
- [x] بنود ميزانية لكل مشروع + مصروفات فعلية + مقارنة مخطَّط/فعلي تلقائية
- [x] قائمة مهام لكل مشروع بحالات (لم تبدأ / جارية / منتهية)
- [x] أوامر تغيير (Change Orders) تُحدّث ميزانية المشروع تلقائياً عند الاعتماد
- [x] سجل يومي للموقع (Daily Log)
- [x] تصدير بيانات الميزانية إلى CSV

## الخطوات التالية (Weeks 4–12، غير مُنفَّذة في هذه السقالة)

1. مولّد عروض الأسعار + عقود بتوقيع إلكتروني (أسبوع 4–5)
2. فوترة وتحصيل عبر Stripe (أسبوع 6)
3. بوابة عميل بصور قبل/بعد + مشاركة اجتماعية بضغطة واحدة (أسبوع 7–9)
4. تنبيهات SMS/بريد لتجاوز الميزانية + خرائط جوجل (أسبوع 10)
5. تجربة تجريبية (Beta) وإطلاق ناعم (أسبوع 11–12)

## ملاحظات أمنية قبل أي استخدام إنتاجي

- غيّر `JWT_SECRET` إلى قيمة عشوائية طويلة.
- لم يُضَف حد لمحاولات تسجيل الدخول (Rate limiting) — مطلوب قبل الإطلاق العام.
- الرفع المباشر للملفات (صور المشروع) غير منفَّذ بعد — سيُضاف في مرحلة بوابة قبل/بعد.
